# site

The public website: Langle's home page (`langle/`) and privacy policy (`langle/privacy/`), plain HTML and CSS.
This folder is copied to the root of the repository `kskt-dev/kskt-dev.github.io`, which GitHub Pages serves at `https://kskt-dev.github.io/` (Langle at `/langle/`).
The privacy policy must change whenever the way Langle handles data changes (and the first-run consent is asked again, `CONSENT_VERSION`).
