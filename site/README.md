This folder is copied to the root of the repository `kskt-dev/kskt-dev.github.io`, which GitHub Pages serves at `https://kskt-dev.github.io/` (Langle at `/langle/`).
The privacy policy must change whenever the way Langle handles data changes (and the first-run consent is asked again, `CONSENT_VERSION`).
`google1ac0ec03cd168137.html` proves ownership to Google Search Console, at the root for `https://kskt-dev.github.io/` (the OAuth consent screen's Authorized domain) and in `langle/` for `https://kskt-dev.github.io/langle/` (the consent screen's home page, which brand verification checks as its own URL-prefix property); keep both.
